# EduNexus – Integrated Campus Management System

## About the Project
EduNexus is a Java-based campus management application that simplifies college administration by managing student details, attendance, fees, and notices through a user-friendly interface.

## Technologies Used
- Java
- Java Swing
- MySQL
- JDBC
- Eclipse IDE

## Features
- Student record management
- Attendance tracking
- Fee management
- College notice management
- Login interface
- MySQL database connectivity

## Requirements
- Java JDK
- Eclipse IDE
- MySQL Server
- MySQL Connector/J

## How to Run
1. Download or clone this repository.
2. Import the project into Eclipse using **File → Import → Existing Projects into Workspace**.
3. Configure your MySQL database connection.
4. Add MySQL Connector/J if required.
5. Run the main Java class.

## Project Purpose
This academic project demonstrates Java programming, database connectivity, and desktop application development.
